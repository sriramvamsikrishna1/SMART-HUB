# Smart CSE Hub

Smart CSE Hub is the official digital platform designed for the Department of Computer Science and Engineering at **Geethanjali Institute of Science and Technology (GIST)**. It serves as a unified hub for students, faculty members, and department administrators to access academic resources, manage departmental workflows, and streamline collaboration.

---

| Layer | Technologies |
| :--- | :--- |

## Getting Started

### Prerequisites
- Node.js (v18+ recommended, detected v24+)
- npm (v9+ recommended, detected v11+)

### Installation
```bash
npm install
```

### Development Server
Run the local Vite development server:
```bash
npm run dev
```
Open your browser at the displayed local URL (default: `http://localhost:5173`).

### Production Build
Check TypeScript compilation and generate the production bundle:
```bash
npm run build
```

### Linting
Run the fast Oxlint linter:
```bash
npm run lint
```
